# My Soundpad

## Kurulum

```bash
pip install sounddevice soundfile
```

Windows'a VB-CABLE kur:
https://vb-audio.com/Cable/

Ses dosyalarını `sounds` klasörüne koy.

Desteklenen formatlar: WAV, FLAC, OGG.

## Kullanım

- `1` - ilk sesi çal
- `2` - ikinci sesi çal
- ...
- `9` - dokuzuncu sesi çal
- `ESC` - sesi durdur
- `F5` - ses listesini yenile
- `0` - programdan çık

Program sesi `CABLE Input` cihazına gönderir.
Discord/oyun tarafında mikrofon olarak `CABLE Output` seçilmelidir.
