# MyLittleSoundpad

A simple soundpad made with Python.

I made this because I did not want to pay $3 for Soundpad.

It plays my sound files from the `sounds` folder.

**Keys:**
- `1-9` → Play sound
- `ESC` → Stop
- `F5` → Refresh
- `0` → Exit

It supports MP3, WAV, FLAC and OGG.

I made it for my own PC, so the speaker name in the code is my own speaker.

Simple, small, and it works.
